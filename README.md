# VideoTool – Downloads

Hier liegen die Installer (`VideoTool-Setup-<Version>.exe`) unter **Releases**.
Installierte VideoTools prüfen dieses Repository beim Start und bieten neue Versionen als Update an.

- Voraussetzungen und Ablauf: siehe `docs/INSTALLATION.md` im Programmordner nach der Installation.
- Die KI-Modelle werden beim Installieren direkt von Hugging Face geladen (Lizenzen: `LIZENZEN.txt`).
